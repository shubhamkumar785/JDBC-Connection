# JDBC-Connection
This project demonstrates a JDBC-based Java application that connects to a database, fetches records from a table, and displays them. It includes a FetchData class inside the com.test.model package, which handles database connection, query execution, and result processing.

🚀 Features
- Connects Java application with MySQL database using JDBC
- Executes SQL queries
- Fetches and prints data from the database
- Organized with proper package structure (com.test.model)

⚙️ Technologies Used
- Java (Core Java + JDBC)
- MySQL Database
- Eclipse
